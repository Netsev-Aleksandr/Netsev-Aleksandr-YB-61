# Задание 1. Статистика

Программа обрабатывает последовательность чисел и вычисляет базовые статистические показатели.

## Описание работы
Скрипт принимает строку целых чисел, преобразует её в список и выводит количество элементов, их сумму, минимальное и максимальное значения, а также среднее арифметическое (округленное до 2 знаков после запятой).

## Особенности реализации
* Запрещено использование встроенных функций `min()` и `max()`.
* Реализована защита от деления на ноль при подсчете среднего значения.
* Если пользователь отправляет пустую строку, программа не падает, а выводит сообщение `Нет данных`.

## Примеры проверок
* **Обычный ввод:** `-2 0 5 3`  
  *Результат:* Количество 4, сумма 6, минимум -2, максимум 5, среднее 1.50
* **Один элемент:** `8`  
  *Результат:* Количество 1, сумма 8, минимум 8, максимум 8, среднее 8.00
* **Пустой ввод:** ` `  
  *Результат:* `Нет данных`
# Задание 2. Независимое преобразование

Программа для модификации элементов списка без изменения первоначальной структуры данных.

## Описание работы
Скрипт принимает на вход строку целых чисел и генерирует на её основе новый список, в котором все отрицательные числа заменяются их абсолютными значениями (модулями). Положительные числа и нули остаются без изменений.

## Особенности реализации
* Исходный список гарантированно сохраняется в первоначальном виде.
* Программа корректно обрабатывает пустой ввод (выводит два пустых списка `[]`).

## Примеры проверок
* **Стандартный тест:** `-2 0 5 -2`  
  *Исходный список:* `[-2, 0, 5, -2]`  
  *Новый список:* `[2, 0, 5, 2]`
* **Пустой ввод:** ` `  
  *Исходный список:* `[]`  
  *Новый список:* `[]`
# Задание 3. Позиции максимума

Программа определяет местоположение всех самых больших элементов в переданной последовательности чисел.

## Описание работы
Скрипт ищет наибольшее число в списке и выводит упорядоченный по возрастанию список всех индексов, на которых это число встречается. 

## Особенности реализации
* Поиск индексов осуществляется при помощи оптимального обхода через встроенную функцию `enumerate()`.
* При обработке пустой строки выводится сообщение `Нет данных`.

## Примеры проверок
* **Несколько максимумов:** `7 7`  
  *Результат:* `[0, 1]` (число 7 стоит на индексах 0 и 1)
* **Один максимум:** `-3 -1 -2`  
  *Результат:* `[1]` (максимум -1 стоит на индексе 1)
* **Пустой ввод:** ` `  
  *Результат:* `Нет данных`
# Задание 4. Индивидуальный вариант №11 (+ Дополнительные задания)

Программа фильтрует список чисел по индивидуальному условию, собирает статистику и очищает данные от дубликатов.

## Критерий Варианта №11
В итоговую выборку попадают только **числа с модулем не больше 3** (то есть числа, удовлетворяющие условию $|x| \le 3$). 

## Описание дополнительных заданий
1. **Обработка крайних случаев:** Программа устойчива к пустому вводу или вводу без совпадений. Вместо падения она выводит пустые списки и нули.
2. **Удаление повторов без `set`:** Из отфильтрованного списка удаляются все дубликаты. При этом строго сохраняется порядок их первого появления. Алгоритм реализован с помощью перебора элементов в цикле и проверки через оператор `not in`, что исключает применение запрещенного множества `set`.

## Примеры проверок

* **Контрольный ввод с повторами:** `-8 -3 1 0 1 6 -3`
  * Подходят под условие: `[-3, 1, 0, 1, -3]`
  * *Вывод программы:*
    Результат — [-3, 1, 0, 1, -3]
    Количество 5
    Сумма -4
    Сортированная копия [-3, -3, 0, 1, 1]
    Без повторов [-3, 1, 0]

* **Пример из текста задания:** `3 1 3 2 1` (все модули $\le 3$)
  * *Вывод программы:*
    Результат — [3, 1, 3, 2, 1]
    Количество 5
    Сумма 10
    Сортированная копия [1, 1, 2, 3, 3]
    Без повторов [3, 1, 2]

* **Ввод без совпадений:** `10 -20 40 5`
  * *Вывод программы:*
    Результат — []
    Количество 0
    Сумма 0
    Сортированная копия []
    Без повторов []
