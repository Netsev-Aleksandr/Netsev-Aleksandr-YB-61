# Документация задания: Поиск и исправление ошибок

## Описание исправлений и проверок

### Фрагмент А: Сумма чисел вместо склеивания строк
* **Причина ошибки:** Переменные `first` и `second` содержали строковые значения `"2"` и `"3"` (в кавычках). Оператор `+` склеивал их в строку `"23"`.
* **Исправление:** Кавычки удалены. Значения стали целыми числами (`int`), что позволило получить математическую сумму `5`.
* **Типы данных:** До исправления — `str`, после исправления — `int`.

### Фрагмент Б: Возраст через год (Сложение строки с числом)
* **Причина ошибки:** Функция `input()` считывает ввод пользователя как строку (`str`). Попытка сложить строку с числом `1` вызывала ошибку `TypeError`.
* **Исправление:** Ввод пользователя явно преобразован в целое число с помощью функции `int()`. При вводе `17` программа корректно выводит `18`.
* **Типы данных:** До преобразования — `str`, после преобразования — `int`.

### Фрагмент В: Среднее арифметическое трех чисел
* **Причина ошибки:** В выражении `first + second + third / 3` нарушен математический приоритет. Сначала делилось число `third` на `3`, а затем прибавлялись остальные числа. Результат получался неверным (`14.33`).
* **Исправление:** Сумма чисел взята в круглые скобки: `(first + second + third) / 3`. Теперь сначала считается общая сумма, а затем она делится на 3.

* **Использование третьей переменной:** Значения меняются местами строго через промежуточную переменную `temp`.

# Документация задания: Индивидуальный вариант №11

## Выполненные проверки и ограничения
* **Типы данных:** Количество единиц автоматически переводится в целое число (`int`), а все денежные показатели (цены, доставка, оплата) — в дробные числа (`float`).
* **Форматирование:** Вывод всех расчитанных и введённых денежных сумм ограничен ровно двумя знаками после точки (`:.2f`), согласно техническому заданию.

## Тестирование и ручной просчёт ожидаемых значений

Перед запуском программы был выполнен независимый ручной расчёт тестового сценария.

### Исходные тестовые данные:
1. Название заказа: `Магазин растений`
2. Имя заказчика: `Елена`
3. Позиция 1 (Саженцы): Количество = `5` шт., Цена = `250.50` руб.
4. Позиция 2 (Горшки): Количество = `4` шт., Цена = `120.00` руб.
5. Стоимость доставки: `350.00` руб.
6. Внесённая сумма: `2000.00` руб.

### Математический расчёт вручную:
* Стоимость Саженцев: 5 × 250.50 = 1252.50 руб.
* Стоимость Горшков: 4 × 120.00 = 480.00 руб.
* Всего предметов: 5 + 4 = 9 шт.
* Стоимость товаров без доставки: 1252.50 + 480.00 = 1732.50 руб.
* Общая сумма с доставкой: 1732.50 + 350.00 = 2082.50 руб.
* Сдача с 2500.00 руб. (изменим тестовый ввод оплаты на 2500.00, чтобы покрыть сумму заказа): 2500.00 - 2082.50 = 417.50 руб.

## Дополнительное задание:
В программу добавлена возможность применения процентной скидки на заказ со следующими условиями:
* **Изолированность скидки:** Процент уменьшает только стоимость самих товаров (`Саженцы` и `Горшки`). Стоимость доставки остается неизменной.
* **Математический расчет:** Программа вычисляет величину скидки в денежном эквиваленте и вычитает её до прибавления цены доставки.
* **Форматирование:** Вывод размера скидки в рублях и новой итоговой суммы округляется до двух знаков после запятой (`:.2f`).

### Тестирование дополнительного задания (Пример)
