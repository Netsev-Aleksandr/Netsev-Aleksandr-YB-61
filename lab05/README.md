# Задание 1. Нормализация текста

Скрипт предназначен для очистки строки от избыточных пробельных символов с сохранением регистра букв.

## Описание работы
Программа принимает на вход строку, удаляет пробелы по краям, а все повторяющиеся последовательности пробелов внутри строки заменяет на один одиночный пробел. Знаки пунктуации при этом остаются частью слов.

## Выводимые данные
* Исходная длина строки
* Новая длина строки после нормализации
* Нормализованный текст
* Количество слов в тексте (разделенных через `split()`)

## Примеры проверок
* `Один   два` -> `Один два`, слов 2, длина результата 8.
* Пустая строка -> длина 0, слов 0.
# Задание 2. Проверка на палиндром (+ Дополнительное задание)

Программа проверяет, является ли введенный текст палиндромом, двумя разными способами и сравнивает их результаты.

## Правила проверки
1. Регистр букв игнорируется (все буквы переводятся в нижний регистр).
2. Обычные пробелы удаляются перед проверкой.
3. Знаки препинания (если они есть) учитываются при сравнении.
4. Если введена пустая строка или только пробелы, выводится сообщение `Нет текста`.

## Дополнительное задание: Реализация без среза
В программе написаны два независимых алгоритма:
* **Способ 1:** Строка сравнивается со своей перевернутой копией через срез `[::-1]`.
* **Способ 2 (Дополнительный):** Строка проверяется в цикле `for`. Мы попарно сравниваем символы с начала и с конца строки, двигаясь к центру. Если хотя бы одна пара букв не совпала, цикл завершается.

В конце программы результаты работы обоих способов сравниваются между собой.

## Примеры проверок
* **Ввод:** `А роза упала на лапу Азора`
  * *Вывод:* 
    Способ со срезом: Палиндром
    Способ с циклом: Палиндром
    Результаты обоих способов совпали!
* **Ввод:** `Привет`
  * *Вывод:* 
    Способ со срезом: Не палиндром
    Способ с циклом: Не палиндром
    Результаты обоих способов совпали!
* **Ввод:** `    ` (только пробелы)
  * *Вывод:* `Нет текста`

# Задание 3. Замена с подсчётом

Программа для подсчёта и замены определённых символов в тексте.

## Описание работы
Скрипт принимает строку от пользователя, сначала подсчитывает количество всех вхождений двоеточий (`:`) в исходном тексте, а затем заменяет каждое двоеточие на дефис (`-`).

## Выводимые данные
* Количество выполненных замен
* Изменённая строка

## Примеры проверок
* `a::b` -> `a--b` (замен: 3)
* `abc` -> `abc` (без изменений, замен: 0)
# Задание 4. Индивидуальный вариант №11 (+ Доп. задание)

Программа для фильтрации и подсчёта слов в строке по заданному критерию длины с обработкой граничных случаев.

## Алгоритм обработки
1. Введённая строка разбивается на отдельные слова по пробелам.
2. Для каждого слова удаляются символы `.,!?;:` с обоих краёв с помощью `word.strip()`.
3. Слово приводится к нижнему регистру.
4. Пустые результаты после очистки игнорируются.

## Критерий Варианта №11
В итоговый список попадают только те слова, **длина которых составляет от 3 до 5 символов включительно**. Повторяющиеся слова сохраняются.

## Дополнительное задание (Обработка крайних случаев)
В программе реализована защита от некорректного или пустого ввода:
* **Пустой ввод** (или строка из одних пробелов) перехватывается на старте.
* **Строка из знаков препинания** (например, `!!!`) успешно очищается фильтром `if not cleaned: continue`, не вызывая ошибок индексации.
В обоих случаях программа корректно выводит сообщение об отсутствии совпадений.

## Примеры проверок
* **Контрольный текст:** `Анна, армия! Я читаю. Книга, край, рама.`
  * *Результат:* анна, армия, книга, край, рама (Общее количество: 5).
* **Тест доп. задания (Пустой ввод):** ` `
  * *Результат:* `Нет совпадений`, `Количество 0`.
* **Тест доп. задания (Только знаки):** `!!!`
  * *Результат:* `Нет совпадений`, `Количество 0`.
