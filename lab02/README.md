# Документация задания: Разложение времени

## Выполненные проверки и ограничения
* **Операторы `//` и `%`:** Математический расчет выполнен строго с помощью базовых операторов целочисленного деления (`//`) и взятия остатка от деления (`%`).
* **Без библиотек времени:** Модули вроде `time` или `datetime` намеренно не импортировались и не использовались.
* **Часы > 23:** Логика программы корректно обрабатывает значения, превышающие одни сутки (выводит реальное количество полных часов).

## Тестирование и ручной просчёт ожидаемых значений

### Тест 1: Пример из задания (3671 секунда)
* **Математический расчёт вручную:**
  * Часы: 3671 // 3600 = 1 ч.
  * Остаток секунд: 3671 % 3600 = 71 с.
  * Минуты: 71 // 60 = 1 мин.
  * Секунды: 71 % 60 = 11 с.
  * *Ожидаемый вывод:* `1 ч 1 мин 11 с`

* **Фактический результат работы программы:**
  ```text
  Введите количество секунд (>= 0): 3671
  Результат: 1 ч 1 мин 11 с
  ```
### Тест 2: Проверка больших значений (Больше суток — 90065 секунд)

  * Минуты: 65 // 60 = 1 мин.

* **Фактический результат работы программы:**

  ```text
  Результат: 25 ч 1 мин 5 с
  ```

# Документация задания: Стоимость покупки

## Выполненные проверки и особенности
* **Типы данных:** Все входные значения преобразуются в целые числа (`int`), так как по условию цена, количество и суммы задаются в целых рублях.
* **Гарантия корректности:** В соответствии с условием задачи, переданная сумма (`paid`) всегда не меньше стоимости всей покупки, поэтому сдача не может быть отрицательной.

## Тестирование и ручной просчёт ожидаемых значений

### Тест 1: Пример из задания
* **Исходные данные:** Цена = `45`, Количество = `3`, Переданная сумма = `200`
* **Математический расчёт вручную:**
  * Стоимость: 45 × 3 = 135 руб.
  * Сдача: 200 − 135 = 65 руб.
  * *Ожидаемый вывод:* стоимость `135`, сдача `65`.

* **Фактический результат работы программы:**
  ```text
  Введите цену одной тетради в целых рублях: 45
  Введите количество тетрадей: 3
  Введите переданную сумму денег: 200
  Стоимость покупки: 135 руб.
  Сдача: 65 руб.
  ```
### Тест 2:
* **Исходные данные:** Цена = `45`, Количество = `3`, Переданная сумма = `135`
* **Результат:**

# Документация задания: Индивидуальный вариант №11
Программа выполняет расчет необходимого количества упаковочных единиц (тетрадей) для размещения заданного объема информации (страниц), а также рассчитывает геометрические параметры круга по его радиусу. 

Скрипт написан линейно, **без использования условных операторов и циклов**.

## Выполненные проверки и результаты тестирования

### Основное задание (по таблице проверок)

1. **Тест на нулевой объем (`0, 10`):**
   * Вход: Общий объем = `0`, Вместимость = `10`
   * Фактический результат: `Полных 0, остаток 0, всего 0` (Корректно отработал сброс в ноль для пустого объема).

2. **Тест на точное деление (`20, 10`):**
   * Вход: Общий объем = `20`, Вместимость = `10`
   * Фактический результат: `Полных 2, остаток 0, всего 2`.

3. **Тест с остатком (`21, 10`):**
   * Вход: Общий объем = `21`, Вместимость = `10`
   * Фактический результат: `Полных 2, остаток 1, всего 3` (Формула успешно учла необходимость дополнительной тетради для 1 страницы).

### Дополнительное задание (Проверка радиуса 1)

* **Фактический вывод программы при радиусе `1`:**
  ```text
  --- Дополнительное задание ---
  Длина окружности: 6.28
  Площадь круга: 3.14
  ```
  Вывод строго округлен до двух знаков после точки с помощью форматирования `:.2f`.
