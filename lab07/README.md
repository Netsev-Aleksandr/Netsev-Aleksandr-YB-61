# Модуль функций (`functions.py`)

Данный модуль содержит бизнес-логику лабораторной работы в виде изолированных функций. В соответствии с требованиями, внутри функций не используются инструкции `input()` и `print()`.

## Описание функций и примеры

### 1. `sum_digits(number)`
Вычисляет сумму цифр модуля целого числа с помощью поразрядной целочисленной арифметики (`// 10` и `% 10`).
* **Пример 1:** `507` -> `5 + 0 + 7` -> Результат: `12`
* **Пример 2:** `-507` -> модуль `507` -> Результат: `12`
* **Пример 3:** `0` -> Результат: `0`

### 2. `average(numbers)`
Рассчитывает среднее арифметическое элементов списка. Не изменяет структуру исходного переданного списка.
* **Пример 1:** `[2, 4, 6]` -> Результат: `4.0`
* **Пример 2:** `[]` -> Результат: `None`

### 3. `normalize_text(text)`
Приводит строку к нижнему регистру, удаляет пробелы на краях и оставляет строго по одному пробелу между словами.
* **Пример 1:** `"  ПРИВЕТ    Мир  "` -> Результат: `"привет мир"`
* **Пример 2:** `"   "` -> Результат: `""`

### 4. `select_numbers(numbers, threshold)` (Вариант №11)
Фильтрует числовую последовательность. Возвращает новый список элементов, модуль которых строго равен порогу ($|x| = \text{threshold}$). Порядок и дубликаты сохраняются.
* **Пример 1 (Контрольный):** список `[-5, 0, 2, 5]`, порог `2` -> Результат: `[2]` (так как $|2| = 2$)
* **Пример 2 (С совпадениями):** список `[3, -3, 3, 4]`, порог `3` -> Результат: `[3, -3, 3]`
* **Пример 3 (Пустой список):** список `[]`, порог `5` -> Результат: `[]`
# Точка входа приложения (`main.py`)

Скрипт координирует интерактивное взаимодействие с пользователем, запрашивает параметры через терминал и демонстрирует корректность работы всех функций из пакета `functions.py`.

## Обработка крайних случаев
* При пустом вводе числовой строки для вычисления среднего значения программа бесконфликтно выводит заглушку `Нет данных`.
* Ввод текстовых данных с невалидными типами (например, букв вместо числового порога) перехватывается блоками `try-except` для предотвращения аварийного завершения (`ValueError`).

# Модуль тестирования (`test_functions.py`) + Доп. задание

Скрипт автоматической верификации работоспособности кода с применением встроенных инструкций утверждения `assert`.

## Реализованные тест-кейсы

1. **Базовый блок:** Проверка инвариантов для стандартных ситуаций (нулевые значения, обработка регистров, удаление пробельных полей).
2. **Индивидуальный блок (Вариант 11):**
   * Точное соответствие контрольной таблице заданий (`[-5, 0, 2, 5]` при пороге `2` дает `[2]`).
   * Тест поведения на пустых массивах без генерации исключений (`IndexError`/`TypeError`).
   * Проверка сохранения дубликатов на границах диапазонов значений.
   * Контроль иммутабельности: верификация того, что функция отбора возвращает новый отфильтрованный список, оставляя оригинальный объект в памяти нетронутым.
3. **Проверка точности `average`:** Для исключения ошибок округления чисел с плавающей точкой вычисление погрешности реализовано через формулу `abs(actual - expected) < 1e-9`.

## Дополнительное задание: Тестирование палиндрома
В соответствии с требованиями, **тесты для проверки палиндромов спроектированы и написаны в самом верху файла до запуска основного кода**.

### Сценарии тестирования функции `is_palindrome(text)`:
1. **Классический палиндром:** Строка `"А роза упала на лапу Азора"` успешно проходит очистку от пробелов и регистра, возвращая `True`.
2. **Обычная строка (не палиндром):** Для строки `"Привет"` возвращается `False`.
3. **Крайний случай (пустой ввод):** Для строки из одних пробелов `"   "` или полностью пустой строки `""` функция возвращает `False` вместо падения.
4. **Учет знаков препинания:** Строка `"А!"` возвращает `False`, так как знаки препинания (кроме пробелов) не удаляются и нарушают симметрию.


## Инструкция по проведению проверок
Для запуска тестов выполните в терминале команду:
```bash
python test_functions.py
```
При успешном прохождении всех сценариев в консоли отобразится отчет. При обнаружении ошибки выполнение прервется с ошибкой `AssertionError`.
