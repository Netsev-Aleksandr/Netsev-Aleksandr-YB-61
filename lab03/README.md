# Документация задания: Минимум трёх чисел


## Выполненные проверки и ограничения
* **Использование ветвления:** Алгоритм реализован строго через конструкцию `if / elif / else` для отработки логики ветвления.
* **Запрет на встроенные функции:** Встроенные функции `min()`, `max()` и сортировка списков (`sorted()`, `.sort()`) намеренно не использовались.
* **Допуск равных чисел:** Использование операторов «меньше или равно» (`<=`) гарантирует корректную работу скрипта, если два или все три введённых числа будут одинаковыми.

## Тестирование и результаты работы

### Тест 1: Все числа разные
* **Входные данные:** `2`, `10`, `3`
* **Фактический вывод:** `Минимальное число: 2`

### Тест 2: Первое число минимальное
* **Входные данные:** `-4`, `0`, `-2`
* **Фактический вывод:** `Минимальное число: -4`

### Тест 3: Последнее число минимальное
* **Входные данные:** `3`, `2`, `1`
* **Фактический вывод:** `Минимальное число: 1`

### Тест 4: Есть два одинаковых числа
* **Входные данные:** `7`, `4`, `4`
* **Фактический вывод:** `Минимальное число: 4`

### Тест 5: Все три числа равны
* **Входные данные:** `5`, `5`, `5`
* **Фактический вывод:** `Минимальное число: 5`

# Документация задания: Простой калькулятор

## Выполненные проверки и ограничения
* **Защита от опасных функций:** По условиям задания встроенная функция динамического выполнения строк `eval()` полностью исключена из кода.
* **Проверка деления на ноль:** При выборе операции `/` программа отдельно проверяет второе число. Если оно равно `0`, выводится фиксированное сообщение `Деление на ноль запрещено`.
* **Обработка некорректных символов:** Если пользователь введёт любой неподдерживаемый знак (например, `%`, `^`, `?`), калькулятор выдаст сообщение `Неизвестная операция`.
* **Форматирование вещественных чисел:** Вывод успешного математического результата ограничен строго двумя знаками после десятичной точки (`:.2f`).

## Тестирование и результаты работы

### Тест 1: Стандартная операция (Сложение дробных чисел)
* **Входные данные:** Число 1 = `5.25`, Число 2 = `2.1`, Операция = `+`
* **Фактический вывод:** `Результат: 7.35`

### Тест 2: Деление
* **Входные данные:** Число 1 = `7`, Число 2 = `2`, Операция = `/`
* **Фактический вывод:** `Результат: 3.5`

### Тест 3: Округление бесконечной дроби (Деление)
* **Входные данные:** Число 1 = `10`, Число 2 = `3`, Операция = `/`
* **Фактический вывод:** `Результат: 3.33`

### Тест 4: Попытка деления на ноль
* **Входные данные:** Число 1 = `5`, Число 2 = `0`, Операция = `/`
* **Фактический вывод:** `Деление на ноль запрещено`

### Тест 5: Ввод неверного символа
* **Входные данные:** Число 1 = `5`, Число 2 = `2`, Операция = `?`
* **Фактический вывод:** `Неизвестная операция`

# Документация задания: Принадлежность прямоугольнику

## Выполненные проверки и геометрия задачи
* **Границы прямоугольника:** Область поиска жестко задана двойными математическими неравенствами:
  * По оси X: (0 <= x <= 5)
  * По оси Y: (0 <= y <= 3)
* **Включение границ:** Используются нестрогие операторы сравнения (`<=`), благодаря чему точки, лежащие ровно на линиях сторон или в углах фигуры, корректно определяются как `Внутри или на границе`.
* **Тип координат:** Координаты считываются как вещественные числа (`float`), что позволяет проверять точки с дробными значениями.

## Тестирование и результаты работы

### Тест 1: Точка строго внутри области
* **Входные данные:** `x = 2.0`, `y = 2.0`
* **Фактический вывод:** `Внутри или на границе`

### Тест 2: Точка на границе
* **Входные данные:** `x = 5.0`, `y = 3.0`
* **Фактический вывод:** `Внутри или на границе`

### Тест 3: Точка снаружи области
* **Входные данные:** `x = 5.1`, `y = 3.0`
* **Фактический вывод:** `Снаружи`

### Тест 4: Точка в отрицательной зоне
* **Входные данные:** `x = 1.0`, `y = -0.5`
* **Фактический вывод:** `Снаружи`

# Документация задания: Индивидуальный вариант №11 и високосный год

Программа выполняет две задачи с использованием ветвлений `if / elif / else`:
1. Классифицирует заполненность парковки по шкале от 0 до 100 (Вариант 11).
2. Определяет, является ли заданный год високосным по правилам григорианского календаря.

## Выполненные проверки и результаты тестирования

### Часть 1. Основное задание (Заполненность парковки)

Согласно ТЗ, интервалы включают указанные концы. Были протестированы крайние точки диапазона, ошибочные значения, а также числа непосредственно до и после каждого порога (`59`, `60`, `89`, `90`):

| Введённое значение | Ожидаемый результат | Фактический результат программы | Статус проверки |
| :---: | :--- | :--- | :---: |
| `-1` | Ошибка диапазона | Ошибка диапазона | Успешно |
| `0` | Много мест | Много мест | Успешно |
| `59` | Много мест | Много мест | Успешно |
| `60` | Мало мест | Мало мест | Успешно |
| `89` | Мало мест | Мало мест | Успешно |
| `90` | Почти занята | Почти занята | Успешно |
| `100` | Почти занята | Почти занята | Успешно |
| `101` | Ошибка диапазона | Ошибка диапазона | Успешно |

### Часть 2. Дополнительное задание (Високосный год)

Проверка условий деления на `400`, а также на `4` при исключении вековых не-високосных годов (`% 100 != 0`). Все обязательные тесты из задания пройдены:

* **Вход:** `1900` → **Вывод:** `нет` (Делится на 100, но не на 400)
* **Вход:** `2000` → **Вывод:** `да` (Делится на 400)
* **Вход:** `2024` → **Вывод:** `да` (Делится на 4, не делится на 100)
* **Вход:** `2023` → **Вывод:** `нет` (Не делится на 4)
