# Документация задания: Диапазон в обе стороны

## Логика работы и проверки
* **Автоматический выбор направления:** Программа проверяет условие `a < b`. Если оно истинно, шаг цикла (`step`) устанавливается в `1` (возрастание). В противном случае шаг равен `-1` (убывание).
* **Включение границ:** Граница \(b\) гарантированно включается в вывод благодаря вычислению конечной точки диапазона как `b + step`.
* **Обработка равенства:** При равенстве границ цикл выполняет ровно одну итерацию и выводит единственное число.

## Результаты тестирования и примеры

### Тест 1: Вывод по возрастанию (\(a < b\))
* **Входные данные:** 
  * Число a: `2`
  * Число b: `4`
* **Вывод в консоли:**
  ```text
  2
  3
  4
  ```
### Тест 2: Вывод по убыванию (\(a > b\))
* **Входные данные:** 
  * Число a: `4`
  * Число b: `2`
* **Вывод в консоли:**
  ```text
  4
  3
  2
  ```
### Тест 3: Равенство границ (\(a = b\))
* **Входные данные:** 
  * Число a: `3`
  * Число b: `3`
* **Вывод в консоли:**
  ```text
  3
  ```
# Документация задания: Статистика потока

## Ограничения и оптимизация памяти
* **Экономия ресурсов:** Программа **не использует списки** или иные структуры данных для хранения элементов. Все метрики рассчитываются «на лету» в процессе чтения.
* **Инициализация максимума:** Переменная `max_val` инициализируется значением самого первого введённого числа. Это гарантирует корректный поиск максимума в потоках, состоящих исключительно из отрицательных чисел (инициализация нулём в таком сценарии дала бы неверный результат).

## Результаты тестирования и примеры

### Тест 1: Поток из отрицательных чисел (Проверка максимума)
* **Входные данные:** 
  * n = `3`
  * Числа: `-5`, `-2`, `-8`
* **Вывод в консоли:**
  ```text
  Сумма -15, положительных 0, максимум -2
  ```
### Тест 2: Минимальный поток из одного элемента
* **Входные данные:** 
  * n = `1`
  * Числа: `0`
* **Вывод в консоли:**
  ```text
  Сумма 0, положительных 0, максимум 0
  ```
# Документация задания: Повторный ввод

## Особенности реализации
* **Условное ожидание:** Использован бесконечный цикл `while True`, который прерывается инструкцией `break` только при получении валидного значения.
* **Счётчик попыток:** Каждая итерация с некорректным значением (\(\le 0\)) увеличивает внутренний счётчик `rejected_attempts`. 

## Результаты тестирования и примеры

### Тест 1: Успешный ввод после нескольких отклонений
* **Входные данные:** 
  * Попытка 1: `0` (отклонено,  <= 0)
  * Попытка 2: `-2` (отклонено, <= 0)
  * Попытка 3: `3` (принято, > 0)
* **Вывод в консоли:**
  ```text
  Квадрат 9, отклонено 2
  ```
# Документация проекта: Вариант №11 и тест простоты

В данном скрипте объединены две расчётные задачи на циклы:
1. **Основная часть:** Потоковый отбор и суммирование чисел по критерию Варианта №11.
2. **Дополнительная часть:** Эффективная проверка числа на простоту.

## Часть 1: Спецификация и тесты Варианта №11

Программа обрабатывает поток из \(n\) чисел. 
* **Критерий отбора:** В итоговую статистику попадают только числа, модуль которых не превышает 3.
* **Контрольный набор:** `-12, -3, 0, 2, 10, 15, 20`

### Примеры проверок:

#### Тест 1.1: Тестирование на контрольном наборе данных
* **Входные данные:** \(n\) = `7`, числа: `-12`, `-3`, `0`, `2`, `10`, `15`, `20`
* **Вывод программы:** `Количество: 3, сумма: -1`

#### Тест 1.2: Обработка пустого ввода
* **Входные данные:** \(n\) = `0`
* **Вывод программы:** `Количество: 0, сумма: 0`

#### Тест 1.3: Отсутствие подходящих элементов в потоке
* **Входные данные:** \(n\) = `3`, числа: `10`, `-5`, `8`
* **Вывод программы:** `Количество: 0, сумма: 0`

## Часть 2: Проверка простоты (Дополнительное задание)

Для проверки простоты применяется эффективный перебор делителей, ограниченный условием `divisor * divisor <= n`.

### Обязательные тесты:

* **Вход:** `2` **Вывод:** `Число 2 — простое`
* **Вход:** `9` **Вывод:** `Число 9 — составное`
* **Вход:** `17` **Вывод:** `Число 17 — простое`
* **Вход:** `49` **Вывод:** `Число 49 — составное`
